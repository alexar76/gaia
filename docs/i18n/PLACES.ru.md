# Места — любой населённый пункт по названию

> 🌐 [English](../PLACES.md) · **Русский** · [Español](PLACES.es.md) · [Français](PLACES.fr.md) · [中文](PLACES.zh.md)

Модель покупателя просит «воздух в Кракове» или «Paris, Texas» — координат и id устройств она не
видела. GAIA находит название в справочнике **GeoNames** — все места с населением от 1000 человек
(171 306 мест), названия стран на 16 языках из Unicode CLDR — и честно говорит о неоднозначности,
а не угадывает.

## `gaia.place.resolve@v1` — бесплатно

```bash
curl -s -X POST https://iot.modelmarket.dev/ai-market/v2/invoke -H 'Content-Type: application/json' \
  -d '{"capability_id":"gaia.place.resolve@v1","input":{"query":"Paris, Texas"}}'
```

Возвращает место (название, регион, страна, координаты, население, часовой пояс, id GeoNames),
остальных кандидатов, сборку справочника, которая ответила (с её SHA-256), и **какие чтения GAIA
покрывают точку** — ближайший ретранслятор (relay) погоды и расстояние до него, качество воздуха
в точной координате, — чтобы следующий вызов был покупкой, а не догадкой. С `latitude` +
`longitude` вместо `query` отвечает ближайшим населённым пунктом (районы города вроде «Mitte»
пропускаются).

## Правила

| Запрос | Результат |
|---|---|
| `Kraków`, `Krakow`, `Краков` | Kraków, Lesser Poland, PL |
| `Paris` | Paris, Île-de-France, FR — самое большое место выбирается, только если оно хотя бы в 5 раз больше следующего |
| `Paris, Texas` · `Paris, TX` | Paris, Texas, US |
| `Toronto, ON` · `Sydney, NSW` | сокращения штатов и провинций работают |
| `Москва, Россия` · `Kraków, Polonia` | страна после запятой — на любом из 16 языков |
| `東京` · `Sài Gòn` · `Kiev` · `Cologne` | альтернативные и исторические названия находят место |
| `Springfield` · `Cambridge` · `Victoria` | **неоднозначно** — отказ со списком кандидатов; добавьте штат или страну |
| `Paris, Narnia` | отказ: уточнение не называет ни страну, ни регион |

Альтернативное название весит в двадцать раз меньше официального, поэтому историческое название
Гонконга «Victoria» больше не перебивает города, которые действительно называются Victoria.

## В чтениях погоды и воздуха

`gaia.weather.read@v1` и `gaia.air.read@v1` принимают те же названия в поле `city`. Города,
которые GAIA ретранслирует, по-прежнему сопоставляются первыми и читают свои ретрансляторы;
любое другое место идёт в справочник. Качество воздуха тогда читается в точной координате.
Погода читается с ближайшего живого ретранслятора не дальше 75 км — или отказ с ближайшим
ретранслятором и расстоянием: «Paris, Texas» больше не «не город, который ретранслирует GAIA», а
место в 1148 км от ближайшего ретранслятора (Чикаго). В ответе указано, откуда взято место
(`place_source`: `gaia-relay-list` или `geonames`), и есть атрибуция GeoNames.

## Операторам

Справочник — один файл SQLite (36 МБ), который собирается при сборке образа командой
`python -m gaia.gazetteer build --out PATH` в отдельной стадии Docker, поэтому обычные правки кода
не скачивают GeoNames заново; чтобы обновить данные, увеличьте `GAZETTEER_EPOCH`. GAIA открывает
его только на чтение из `GAIA_GAZETTEER_PATH`. Без него GAIA, как и раньше, понимает только
ретранслируемые города. Это файл в образе намеренно: неизменяемые справочные данные с той же
версией, что и код, без базы данных, одинаковые в разработке и в проде.
